# Six-task coding pilot, contract s1

Repair the six functions in `utilities.py` to satisfy these contracts. Preserve public signatures, use only Python's standard library, and avoid changing callers' inputs. These are small synthetic maintenance tasks, not a sample of production repositories.

1. `paginate(items, offset, limit)`: return a new list containing up to `limit` values starting at `offset`, retaining order. Reject negative offset or nonpositive limit with ValueError. Offset beyond the end returns empty; accept iterable inputs including generators.
2. `deep_merge(base, overrides)`: recursively merge two dictionaries; keys from overrides replace base values unless both corresponding values are dictionaries. Return a completely independent structure (including nested lists/dictionaries), so mutating the result or either input later does not change the others. Do not mutate inputs. Plain data only, no recursive/cyclic object graphs required.
3. `topological_order(dependencies)`: input maps task names to iterable prerequisite names. Include both mapping keys and prerequisite-only nodes exactly once, with every prerequisite before its dependants. Deterministically choose the lexicographically smallest ready node at each step. Duplicate prerequisite edges count once. A cycle or self-cycle raises ValueError. Empty input returns empty; do not mutate inputs.
4. `parse_csv_rows(text)`: parse CSV with the Python CSV conventions: first logical record is the header, trim header whitespace, quoted commas/newlines are supported, preserve cell whitespace and values as strings. Reject blank or duplicate normalized header names, missing or extra cells with ValueError. Empty input returns empty. Ignore physically blank rows, but not records containing an explicit empty cell. A header-only file returns empty.
5. `ExpiringCache.set(key, value, ttl, now)` / `.get(key, now)`: in-memory cache with absolute expiration `now + ttl`, supplied numeric clock. Nonpositive ttl raises ValueError without changing an existing entry. `get` returns None at or after expiration and removes that entry; before expiration it returns the stored value, including falsey values. Updating a key replaces both value and expiration. Different instances must be independent. No threading or value copying required.
6. `apply_transfers(balances, transfers)`: apply ordered `(source, destination, amount)` transfers on an independent copy of a dictionary of account integer balances. Amounts must be strictly positive integers (bool excluded); both accounts must exist and source must have sufficient funds at that step. Invalid transfer raises ValueError and leaves input unchanged, even if earlier transfers were valid. Source equals destination is allowed when funds suffice and has no net effect. Return all balances with total conserved; empty transfers returns an independent dictionary. Accept a generator of transfers.
