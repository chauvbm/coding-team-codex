## A: bounded streaming data (boltons/module.py)
Add clamp_iter(values, lower=float('-inf'), upper=float('inf')), an iterator applying the existing clamp semantics to each input item. It must stream one-shot or unbounded inputs without consuming items before they are requested, and retain comparable types supported by clamp. Reversed bounds must raise ValueError on first iteration even for empty input. Existing scalar clamp/ceil/floor/Bits behavior must stay unchanged. Include a short docstring.

## B: combination bookmarking (more_itertools/module.py)
Add combination_index(n, positions): return the zero-based lexicographic rank of a combination of positions from range(n), inverse to nth_combination(range(n), len(positions), rank). Positions may be a one-shot iterable, must be strictly increasing distinct integer indices in [0,n); n is a nonnegative integer. Booleans are not valid integers for this new API. Bad types raise TypeError; invalid ranges/order raise ValueError. The empty combination has rank0. Do not enumerate all combinations or allocate a range(n) pool: handle n=1000000000 and short combinations efficiently, using combinatorial arithmetic. Export the new public name consistently with this module's existing convention. Preserve nth_combination behavior.

## C: configuration mapping (dotenv/module.py)
Add parse_mapping(stream, *, strict=False) -> dict, reusing current parse_stream semantics. Ignore comments/blank bindings; retain key-only bindings as None and explicit empty values as ''. Repeated keys use the last parsed value while preserving first insertion order. Preserve quoted/unquoted, escaped and multiline syntax as recognized by parse_stream; do not interpolate environment variables. Non-strict mode skips invalid bindings and continues. Strict mode raises ValueError when an invalid binding is encountered, and its message must identify that binding's original starting line number. Existing parse_stream output/API must not change. No mutation of environment or disk.
